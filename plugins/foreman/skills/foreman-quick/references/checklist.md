# Checklist before handing over a quick prompt

- [ ] Goal in one sentence, audience, platform and stack are named.
- [ ] Must-have, out of scope and success criteria are in the requirements part, each testable.
- [ ] Accessibility line present (required level or "not required").
- [ ] Rule set for `CLAUDE.md` included: precedence, plan and accept, git rules (only `dev`), safety, quality gate, resume line.
- [ ] Work loop is explicit: slices, one commit per slice, `STATE.md` updated per slice, stop rules.
- [ ] Human Testing section required per milestone, with checkable steps.
- [ ] Closing report format is named.
- [ ] No secrets, no tokens, no invented hostnames.
- [ ] Workers: either the delegation block with a prerequisite check, or the self-build block. Not both.
- [ ] Login through a third party: test login in the first milestone, non-production only.
- [ ] Under about 12 KB; references files instead of copying them.
