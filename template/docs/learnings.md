# Learnings

Lessons from this project's runs. Skills hold rules; the story behind a rule lives here. The reflect step (`.claude/skills/foreman-dispatch-run/references/reflect.md`) appends entries after each UAT approval. Newest first. Keep entries short.

## Format

```markdown
### <YYYY-MM-DD> · <unit> · <short title>
- Happened: one or two sentences.
- Cause: why the checks or rules did not stop it.
- Rule: the rule now in force, with the skill and section, or "none yet".
- Skill proposal: shorten / merge / delete / sharpen <rule>, or "none".
```
