## Wrapper

Alle Codeaufträge liefen über `tools/delegate/run_task.py` mit einer lokalen Config (echte Modell-IDs). Ein Fehlversuch (Worker ohne Bash-Zugriff, S1-Lint), im zweiten Lauf mit Hinweis im Task ok. Zwei Wrapper-Meldungen "changed outside scope" bei Dateien unter `.github/` (Glob trifft Punkt-Ordner nicht); Änderung war beauftragt. Die Test-Anker für S2, S3, S4 sind Stubs (Wrapper braucht ein lauffähiges `verify`); den echten Test-Rot-Beweis liefert der Lauf gegen `5e090af`.

## Learned

- Eine Messung entscheidet früher als Schätzen: die ersten Kürzungen sahen groß aus, zwei von drei Läufen lagen trotzdem über dem Stand 0.2.1.
- Ein Verweis auf einen Besitzer-Skill gilt nur, wenn der Skill im selben Lauf geladen wird; sonst ist die Ersparnis Schein (Fix-Paket zeigte auf den Milestone-Skill).
- Tests, die einen Git-Stand brauchen, laufen in CI nur mit vollem Klon (`fetch-depth: 0`).
