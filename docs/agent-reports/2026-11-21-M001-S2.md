# M001 S2: Webhook-Format

**Ergebnis:** Fehlermeldungen des Dispatchers gehen je nach `webhook_format` (`discord` → `{"content"}`, `slack` → `{"text"}`, `auto` nach Host) an Discord oder Slack. Unbekannter Host, ungültige oder nicht-https-URL und unbekanntes Format ergeben eine Logzeile `webhook not used: ...` ohne URL, keinen Abbruch, Exit-Code bleibt 1. Neue Funktion `webhookRequest()` in `dispatcher/dispatch.mjs`.

## Offene Punkte
- Verhaltensänderung: ein Webhook mit anderem Host als Discord/Slack bekommt mit `auto` keine Meldung mehr. Wer so einen Webhook nutzt, setzt `webhook_format`. Gehört in den Upgrade-Hinweis für M006.
