## Lernpunkte (Auszug)
- Prüfer ohne Shell finden Lücken in Belegen und Berichten, aber keine Laufzeitfehler; die Sitzung muss jeden Befund selbst gegen den Code prüfen.
- Uhrzeiten und SHAs nur aus `git log` oder Dateizeiten übernehmen.
- Tests, die ein Worker „vor dem Hauptblock“ einfügen soll, laufen sonst nie; nach jedem Testauftrag die Liste der laufenden Testnamen prüfen.
- Fake-`claude` in Tests darf sich nicht auf Umgebungsvariablen verlassen, die Cloud-Sitzungen selbst setzen.
