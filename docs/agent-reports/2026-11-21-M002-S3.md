# M002 S3: Zeitlimit je Rolle

Ergebnis: erledigt. `[roles.<name>] timeout = <Sekunden>` setzt das Zeitlimit eines Versuchs für diese Rolle. Ohne Wert gilt `[defaults] timeout_seconds`. 0, negativ, Text oder Bool wird mit Exit 2 abgelehnt (Rolle und globaler Wert). Ursache bei Ablauf: `timeout after <N>s` mit dem tatsächlichen Wert.

## Rollen
`execution_simple` für Tests (A), Umsetzung (B), Doku (C). Keine Eskalation, kein Ausfall. Der Doku-Worker hat zusätzlich `tools/delegate/config.toml` geändert (Scope-Finding); die Kopie wurde danach ohnehin aus der Vorlage überschrieben, also kein Rest.
